# F035 Theorem 3.2 の独立確認

対象: [arXiv:2411.08314v5](https://arxiv.org/html/2411.08314v5) §3.2 Theorem 3.2、Appendix A.2 式 (A.5)–(A.10)。以下は記載仮定と証明の照合であり、画像・材料実験の成否とは別。

## 証明で使う追加条件

本文の定理は正の条件付き密度、原点近傍 C² の定常等方 kernel（α(0)=1, α′(0)=0, 遠方で0）、有限 E[r²] から、全 θ 共通の定数 C による gradient 誤差 ≤ C E[r²] を主張する。Appendix A.2 冒頭は別途、密度類の無限遠での減衰、積分順序交換に必要な条件、v と ∇θv の有界性、および mini-batch OT が y0≈y1 を与える仮定を明記する。A.6–A.8 はさらに hθ の θ と w にわたる一様上界 H を使う。単なる確率密度の減衰は、対象 drift や ∇θv との積の可積分性、微分と期待値の交換、一様 H を自動的には保証しない。特に Appendix の v が2回記載された箇所は表記どおりでは何を対象とするか不明であり、必要な条件を推定している。

全 θ に共通 C がないことの簡単な検査: u=0、vθ(x,y,t)=θ（実数）、正の Gaussian 状態密度、r=a>0 一定、α(r)=exp(−r²) とする。対応する両目的の差の微分は 2θ(α(a)−1) で、θ を無制限にすると左辺は無限に大きくなるが E[r²]=a² は固定。必要な関係式のもとでこれらを実現できるため、本文に記載の条件だけでは θ に一様な C は得られない。一方、コンパクトな θ 集合などで hθ が一様有界なら、この反例は除外される。

## 二次上界を支える十分条件と残差の注意

微分と期待値の交換、および式 (A.6) が正しいと仮定し、supθ,w ||hθ(w)||≤H、全 r≥0 で |α(r)−1|≤K r² が成り立てば、直接三角不等式により差は HK E[r²] 以下。kernel が原点近傍 C² かつ α′(0)=0 なら近傍で二次上界があり、全域で有界なら遠方にも有限 K を取れる。通常の Gaussian kernel はこれを満たす。ただし C の値は一般に α″(0) だけでなく近傍全体と遠方の上界にも依存し、H はモデルと分布に依存する。

付録 A.8 後の「ρ(r)=o(r²) から E|ρ(r)|=o(E[r²])」は、r の固定分布に対して漸近パラメータがなく、第二モーメントが小さい分布族に対してもそのままは出ない。例えば r=a を確率 ε²/a²、0 を残りの確率でとると E[r²]=ε² だが、ρ(a)≠0 なら E|ρ(r)|/E[r²]=|ρ(a)|/a² は消えない。大域二次上界による O(E[r²]) の結論にはこの little-o は不要であり、refined な展開 A.10 には少なくとも r² で重み付けした相対的な集中など追加条件が必要。点ごとの little-o だけでは dominated convergence の支配関数・正規化後の収束が未確立。

## 結論

本文に列挙された条件だけから全 θ 一様の主張は支持されず、付録にある有界性・交換可能性を十分に強く明示すれば O(E[r²]) は直接得られる。A.10 のより強い little-o はさらに分布族の集中条件が必要。条件を付けた上界は実際の DINO future paired MSE 改善や有限モデルの一般化を保証しない。
