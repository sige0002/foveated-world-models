# 観測外乱を周辺化するStage 1：理論から組み立てる研究候補

2026-11-12。未採用・ニューラルモデル未実装。前の時間容量配分案を撤回した後の提案。理論上の恒等式、既存の統計手法、実験が必要な拡張を区別する。

## 問題と提案

潜在行動で実現された未来特徴をすべて再構成させると、偶然のカメラ揺れもzへ符号化する利益がある。現実装はSmooth L1とGaussian VAEのKLを使うが、カメラに起因する誤差の相関構造は明示しない。次元を32から64や128に増やすことは妥当な比較だが、この学習誘因は次元数だけでは解消しない。

提案は、カメラ成分を正解としてzへ押し込む代わりに、既知または外部校正した観測外乱の分布として積分すること。LaWMは行動に対応する条件付き平均を出し、観測には構造化された不確かさを認める。背景maskや重要フレーム選択器は必要としない。

## 成立条件を限定した理論

固定した開始状態の近傍で、中心化した特徴変化を y = Aa + n と置く。aは操作効果の座標、nはカメラ等の外乱。仮定は (1) 局所線形近似、(2) aとnが無相関、(3) 外乱共分散Nが別の介入から既知、(4) Aが列フルランクで操作共分散が正定値。すると

\[
 \operatorname{Cov}(y)-N=A\operatorname{Cov}(a)A^\top.
\]

右辺の像はAの像と等しい。したがって母集団共分散が分かる理想条件では、外乱と操作の方向が重なっていても操作の部分空間が分かる。操作座標の一意性や、一回の観測から真のaを完全回復できることは意味しない。有限標本・未知状態・推定誤差は別の問題。

対して、特徴変化を低ランク線形autoencoderで二乗再構成する理想化では、大きな分散の方向が優先される。A=(1,1)^T、Var(a)=1、N=diag(100,1)なら観測共分散は[[101,1],[1,2]]。通常の第1主成分と操作方向の角度は約44.42度だが、Nを差し引いた行列の第1固有方向は操作方向と一致する。NumPyの固有分解で確認済み。これは母集団の2次元例で、LaWAMの精度改善の実測ではない。

確率モデル y|a ~ N(Aa,N), a ~ N(0,I)では、事後平均は

\[
 E[a\mid y]=(I+A^\top N^{-1}A)^{-1}A^\top N^{-1}y.
\]

雑音が大きい方向の寄与を連続的に小さくするが、その方向を削除しない。外乱方向への直交射影は、そこに重なる操作成分も削除する。事後平均の外乱依存は一般にゼロにはならず、完全なカメラ不変性を保証する提案ではない。

以上は既存の因子分析・線形Gaussian推定の帰結で、新定理ではない。非線形IDMへ同じ保証がそのまま移るとは主張しない。

## 実装できる最小構成

1. 最初は既存固定視点RoboMINDへ、操作と独立な小さい2D平行移動を加える。カメラ揺れの分布を既知にする。この段階で実際の3D視点変化を模擬したとは呼ばない。
2. 同じ画像を±微小変位した凍結DINO特徴の有限差分で、外乱への局所応答Bを測る。最初は水平・垂直の2方向で4回の追加DINO forward。回転・スケールは後に追加。学習用追加処理として費用を計上する。
3. 変位分布の共分散ΓからN(u)=B(u)ΓB(u)^T+σ²Iを構築する。σ²>0。初期版ではNを学習させず固定し、誤差を大きい分散へ逃がす経路を作らない。Bを現在画像で近似する誤差は測る必要があり、大きい操作・遮蔽では近似が崩れ得る。
4. IDMとLaWMは既存構造を使い、特徴誤差e=u_T-F(u_t,z)の損失を、0.5 e^T N(u_t)^(-1)e + 0.5 log det N(u_t)へ置き換える。VAEのKLと既存状態補助損失を維持する。Gaussian尤度の正しいスケールでKL係数1の場合と、β-VAEとして調整した場合を区別し、現設定の5e-5を無条件に流用しない。
5. zは32・64・128で比較し、次元を提案の前提条件にしない。巨大な特徴共分散行列は生成しない。N=σ²I+UU^TとしてWoodbury公式と小さい行列のCholesky分解で二次形式を計算する。

この損失はGaussian外乱を積分した尤度から導ける。ただしqが未来を見ているため、損失の重みを変えただけで外乱を符号化しなくなるという保証はない。正しく指定した線形Gaussian生成モデルの母集団最尤解と、ニューラルVAEの有限標本・変分近似・最適化は区別する。KL除去、過剰容量、対角事後分布の近似誤差は必ず診断する。

LaWMの平均出力は、偶然の揺れを取り除いた条件付き平均を狙う。実際の未来カメラ姿勢を当てる手法ではない。生の揺れた未来のMSEだけで評価すると目的が異なるため、固定座標の真値、物体状態readout、カメラ条件付き予測、確率予測の校正を分ける。真の未来画像や姿勢を推論入力へ追加しない。

## 研究としての差分と反証

外乱がzへ入る理論は既に[Why Latent Actions Fail, and How to Prevent It](https://arxiv.org/html/2605.20223)が扱い、cross-exogenous再構成とCCA、補助教師の効果まで解析している。ノイズを考慮した因子分析も[PPCAの基礎文献](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/02/bishop-ppca-jrss.pdf)等の既存統計学である。

[WING](https://arxiv.org/html/2610.03607v1)の相互作用蒸留、[CD-LAM](https://arxiv.org/html/2607.09185)の領域重み・対比・校正、[ACT-LAM](https://arxiv.org/html/2609.15189)のIDM/FDM構造変更も比較対象。独立したcamera augmentationだけで改善する基準、cross-exogenous再構成、単純な損失重み付けに勝つ必要がある。

投稿価値を狙う差分は、操作と外乱の特徴方向が重なる条件について、外乱除去と確率的な周辺化の違いを明らかにし、凍結特徴空間で外乱分布を校正する実装と誤差条件を示すこと。『Mahalanobis損失を追加した』だけでは弱い。今回の検索で完全一致の手法は確認していないが、不在や新規性の証明ではない。

必要な理論拡張は、有限差分で得たBの誤差・非線形剰余・共分散推定誤差が、回復される部分空間へ与える影響の上界。出発点として、共分散差の誤差がEで固有値gapがγなら、gapが保たれる領域で部分空間誤差は概ね||E||/γに制約される。定数・確率・仮定を含む新たな定理はまだ証明していない。

比較は元Smooth L1、等方Gaussian、対角共分散、構造化低ランク共分散、カメラ方向の射影除去、独立augmentation、cross-exogenous再構成、利用可能なWING/CD-LAM型基準。元の補助状態損失は共通。外乱強度・操作との方向の重なり・共分散校正誤差を独立に変える。

中止条件は、(1) 正しいNが分かる線形実験でも期待した違いが出ない、(2) DINO応答の局所近似が対象の揺れで成立しない、(3) 同予算の独立augmentationや対角重みと同等、(4) 物体情報を落としただけでカメラ感度が下がる、のいずれか。相関した視線移動、3D視差、大きい遮蔽は当初の保証外。人間動画全体へ一般化する前に別実験が必要。

今回確認したのはコード、一次資料の関係する方法・理論、2次元母集団例。DINO上の仮定と実データでの効果は未確認。実装可能性を持ち、失敗条件も数学的に記述できる研究候補として提案する。
