# ローカルzの追加診断と公式配布重みの評価

2026-11-13。**公式配布LaWAMではzが有効に使われていた。ローカルfinal10000の現象は、LaWAM一般の崩壊として扱えない。** モデルを再学習せず、VAEの平均・分散・サンプリング、encoderからAdaLNまでの表現、同じ現在特徴に対する条件差替えを測定した。

## 評価対象と整合性

ローカルは従来の`stage1-robomind-main/checkpoints/final.ckpt`、公式は[配布checkpoint](https://huggingface.co/jialei02/lawam_lam/blob/bd993da2a0861afaac5a95ac86d2555b1313ab8c/checkpoints/pytorch_model.pt)。公式ファイルのSHA256 `57c31dcba13c2998c4e866cdcfc427f14ae3c1b762a586778276e2100b48af88`が配布LFS情報と一致した。encoder・VAE・decoderはそれぞれstrict loadした。

両checkpointのDINO重み211テンソルは完全一致。Transformersのコンテナ名`model.model.layer`／`model.layer`の違いだけを対応付けて検査した。同じ特徴抽出設定なので既存の画像特徴を共用できる。主評価は既存train512で平均zを計算し、validation64・再利用test170で評価。学習済み重みは固定、FP32 highest、augmentationなし。testは新しい盲検集合ではない。

## 公式配布モデルのz定数化

同じpadding前処理・同じtest170での比較。低いMSEが良い。

| 指標 | ローカルfinal10000 | 公式配布重み |
|---|---:|---:|
| 通常μのMSE | 0.11478951 | 0.15954206 |
| train平均定数zのMSE | 0.11478867 | 0.22857819 |
| 定数化によるMSE増加 | -0.00073% | **+43.27%** |
| 交換zのMSE | 0.11478900 | 0.19827607 |
| 定数化による出力差RMS／実際の特徴変化RMS | 0.0222% | **61.88%** |
| μの例間分散和 | 3.02e-5 | 5.89 |
| μの変動の有効rank | 1.02 | 4.22 |

公式の平均定数化によるMSE差は+0.06904、7動画グループのpaired bootstrap 95%区間は[+0.05068,+0.09617]。固定checkpointと再利用集合に条件付けた区間であり、未見タスクへの一般化の保証ではない。

ローカルpaddingではローカルモデルの絶対MSEの方が低い。**予測MSEの良さと、zの追加価値は別の評価軸**である。公式のz有効性を、そのまま全設定での精度優位とは解釈しない。

## 前処理を公式に合わせても結論は維持

trainから等間隔に64例、testから等間隔に32例を選び、同じ画像・時刻を両前処理へ通した。平均zは各条件のtrain64だけから計算。公式FR3経路の中央crop（最大4:3）＋bilinear resizeを再現した。元画像からのpadding特徴再抽出は保存cacheと最大差0。crop/resizeは公式ソースから抽出したメソッドと5種類の画像サイズで要素ごとに一致した。依存パッケージ不足のためStarVLAの全データローダーを実行したものではなく、同じoverhead view・1.2秒ペアに画像変換だけを適用した確認である。

| モデル・画像前処理 | 通常μ MSE | 平均定数 MSE | 定数化での増加 |
|---|---:|---:|---:|
| ローカル・padding | 0.118394 | 0.118392 | -0.0022% |
| ローカル・公式crop/resize | 0.250774 | 0.250775 | +0.00052% |
| 公式配布・padding | 0.172291 | 0.234934 | +36.36% |
| 公式配布・公式crop/resize | **0.154358** | 0.315764 | **+104.57%** |

前処理で絶対精度は大きく変わるが、ローカルのz依存性の弱さは、推論時のcrop変更だけでは回復しない。これは学習時の前処理が原因かどうかを検証した実験ではない。

## 「μだけ小さくても、サンプルzは定数とは限らない」の検証

その留保は正しい。さらに今回、ローカルtrain512で以下を確認した。

- μの例間分散和：5.36e-5。
- 条件付きノイズ分散和 E[Σσ²]：1.4473。
- 全分散の分解 Var(z)=Var(μ)+E[Σσ²] では、**99.9963%が条件付きノイズ**。
- logσ²の例間分散和も2.90e-5と小さい。

4回の共通乱数サンプリングで、ローカルtestの通常サンプルzのMSEは0.11505499。μとσを両方train共通値へ固定して同じ乱数を与えたMSEは0.11505412、出力差MSEは1.21e-8だった。固定σはtrainの平均条件付き分散の平方根を用いる。**「μだけ一定で、σ側が予測に必要な例固有情報を運んでいる」という説明も今回の結果では支持されない。**

参考として、有限個の評価例を一様に選ぶ対角Gaussian混合の1回のサンプルzについて、Gaussian最大エントロピーによる例IDとの相互情報量上限はtrainで0.000653 natsだった。これはこの経験分布・確率的な1回のサンプルに限る上限で、決定的μの情報量や実環境の条件付き未来情報量を測った値ではない。公式のように一部次元へ情報が集中する場合、全次元を足した信号／ノイズ比だけで有用性を判定することもできない。

一方、公式testではサンプリング時も、μを固定するとMSEが0.159795から0.228585へ悪化する。推論時μに限らないz利用が確認された。

## どの段階で変動が弱いか

train512の「例間分散／平均二乗ノルム」。各層で尺度が異なるので絶対分散だけを並べず、共通成分に対する比率を示す。これは幾何学的な診断であり、情報損失の因果証明ではない。

| 段階 | ローカル | 公式配布 |
|---|---:|---:|
| QFormer query（1024次元） | 3.20e-4 | 0.1483 |
| encoder nodes（32次元） | 9.89e-5 | 0.3436 |
| VAE.pre_norm | 4.95e-6 | 0.3314 |
| μ | 9.57e-5 | 0.7387 |
| decoder action_in_proj | 2.31e-5 | 0.1570 |
| decoder最初のAdaLN modulation | 2.45e-7 | 0.1394 |

ローカルはVAEに入る前のqueryから共通成分が支配的で、LayerNorm後の相対変動も小さい。したがってdecoderだけの問題とは言いにくい。ただし、queryのどの内部層・どの更新時点でこの状態になったかは未同定。

[公式decoder](https://github.com/RLinf/LaWAM/blob/c12168d9077edea67fe7c1b70d08b80b8e65a9c8/latent_action_model/core/utils/lam_decoder.py)のz経路は`action_in_proj → SiLU/Linear → AdaLNのshift/scale/gate`。z自体をさらにLayerNormする層はない。AdaLNのLayerNorm対象は視覚トークンである。「decoderに渡す投影・正規化後のz」という表現は、この実装では修正が必要。

## KLと現在特徴依存の解釈

公式とローカルで[同じVAE計算](https://github.com/RLinf/LaWAM/blob/c12168d9077edea67fe7c1b70d08b80b8e65a9c8/latent_action_model/core/vq.py)を使う。β=5e-5は両公開設定に対するコード既定値。係数の数値だけでは勾配の影響は決まらない。

ローカルのKL(q(z|x)||N(0,I))は約35.60 nats、βを掛けると0.001780。qが標準正規へ一致している状態ではないので、ここでは「入力依存性の弱い表現」と記述する方が正確。validation先頭8例で、32次元nodesに対するKL勾配ノルムは再構成勾配の約4.16%だった。ただしこれはcheckpoint固定・augmentationなし・4回のサンプル・状態補助損失除外での観測であり、過去の学習中にKLが崩壊を引き起こしたかは判断できない。

現在特徴を固定し、encoderに与える未来だけを別例へ循環交換した場合、ローカルの出力差MSEは8.33e-9、公式は0.05593だった。公式ではその変更で元の正解未来へのMSEも0.15954→0.20233へ悪化する。ただし別シーンの未来を組み合わせた入力は不整合になり得る。これは未来依存性の検査であり、「同じ現在から右／左に動く正しい未来へ分岐できた」という実証ではない。その評価には同じ初期状態からの複数の実遷移・シミュレーションなどが必要。

既存の定数z学習対照と合わせると、ローカルで現在特徴から予測する経路が強いという説明は支持される。ただし、背景が原因かはROI別の評価なしには断定できない。現在特徴をそのままコピーするtest MSEは0.23986であり、単純コピーだけが元モデルと同等という結果でもない。

## 次の切り分け：データ・学習ハイパラは固定

以下は検討案。ユーザーの「修正はまだ」という指示に従い、学習用前処理の変更・新しい学習は実行していない。カメラ解像度と姿勢規約についての訂正は[差分の整理](local-official-data-contract-gaps.md)を参照。

ユーザー指定により、データの種類・分割・選択、batch、学習率、warmup、更新数は今回は変えない。残る前処理差は以下。

1. 状態教師：公式FR3は各腕の位置3＋姿勢3＋gripper1をmin–max正規化。姿勢フィールド名はrotvecだがコメントはRPYと食い違い、厳密な規約は未確定。ローカルは各腕の位置3＋姿勢6（RPY由来rot6D）＋gripper1、位置はm、統計正規化なし。損失式は同じでも、単位・有効次元・状態予測器の入出力サイズが異なる。姿勢表現変更と正規化は別要因なので、まず20次元を保持した正規化だけの対照にすれば影響を分離できる。これは公式状態表現の完全再現ではない。
2. 画像：公式は横長画像の左右を中央crop後に256×256へbilinear resize。ローカルは全体の縦横比を保持したbicubic縮小＋黒padding。1280×720なら、公式は960×720へcrop→256×256、ローカルは256×144→上下56pxずつpadding。視野、対象サイズ、背景割合が変わる。

trainだけで推定する状態正規化、公式crop/resizeを別々のフラグにし、共通初期値・データ順・ハイパラで切り分けるのが次の検証。今回の作業では新しい学習は開始していない。
