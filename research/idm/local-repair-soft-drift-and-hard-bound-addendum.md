## Candidate for later consideration: a bounded residual on a frozen reference

Let the fixed reference posterior be `q0=N(μ0,diag(σ0²))`, with its original logvariance clamp. For dimension d=32 and a prespecified radius δ, define

```
μθ(q) = μ0(q) + σ0(q) * sqrt(2δ/d) * tanh(gθ(q))
qθ    = N(μθ(q), diag(σ0(q)²)).
```

Freeze both μ0 and σ0. Initialize the final layer of g to zero, so every example starts exactly at H0. Then, in exact arithmetic,

`KL(qθ||q0) = (δ/d) Σ_j tanh²(gθ(q)_j) ≤ δ`

for **every input**, not merely the observed minibatch mean. The fixed32D variance is essential to this identity. A learned variance would invalidate this bound. Finite implementation must also check finite inputs/outputs and numerical KL≤δ plus a declared floating-point tolerance, with no evaluation-dependent radius change.

This is a conventional trust-region-style parameterization, not a novel principle or theorem. It constrains a coordinate-wise box inside the whitened Mahalanobis ball, so it is conservative and depends on the chosen whitened coordinates. It is not equivalent to optimizing freely over that ball. Saturated tanh can suppress gradients.

The interpretation is **local readout repair, not information removal**: the reference μ0 is retained and a bounded adjustment is added. However, a bounded adjustment can still overwrite or encode distinctions; the constraint does not preserve action semantics, prohibit camera content, or bound information in deterministic μ. In joint training, a decoder can amplify small mean differences; the Gaussian KL constraint does not bound prediction changes without additional decoder regularity. Thus actual reconstruction and independent physical-effect probes remain necessary.

If the completed probes justify another experiment, compare bounded and unbounded residual adapters with the **same frozen reference, g architecture, initialization, and local Jacobian scale**. An unbounded counterpart is `μ0+σ0*sqrt(2δ/d)*gθ(q)`. Keep any soft penalty identical across those counterparts to isolate the bounding map. The existing full-head soft-penalty H/HD runs are informative historical results but not a matched architecture control for this new residual adapter. A frozen-decoder pair isolates head repair most directly; a joint-decoder result has the additional amplification ambiguity.

Do not expand to this experiment merely because a hard constraint is mathematically available. First read the completed fixed-code D control and independent interaction/swap evaluations. Reject the bounded repair if it cannot beat matched decoder-only/current-only controls on visual MSE while respecting its bound, if gains only appear when δ is selected using observed64/96, or if physical utility deteriorates while claiming better action representation. Keep the original12-run conclusions and all scope failures visible.

The existing data are robot-only and the measured8D endpoint increments are not command chunks. On human video, visual reconstruction remains possible without those labels, but action/camera discrimination cannot be certified by this bound. Real head motion may be needed to predict the next view; no camera-removal claim follows.
