# Prepared independent evaluation of completed local repair

No new probe or future-swap evaluation has been executed during preparation. After explicit authorization, completed D42/HD42 checkpoints were loaded solely to validate checkpoint schema and exact mean-code identities. Shared trainers and running jobs are unchanged. Both entry points enforce CPU2/highest precision and require all nine completed H/D/HD checkpoints for minibatch seeds42/43/44. A completed `results.json`, checkpoint, protocol, and preflight must have matching hashes and identities; step400 and immutable input/anchor hashes are checked. Scope-failed drift runs remain in the output rather than being discarded.

Create a JSON object whose nine keys are `H42,H43,H44,D42,D43,D44,HD42,HD43,HD44`, with each value the corresponding completed run directory. Then, from the repository root:

```sh
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=2 .venv/bin/python research/idm/evaluate_local_repair_swaps.py --runs-json PATH.json --output NEW_SWAP_DIRECTORY
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=2 .venv/bin/python research/idm/evaluate_local_repair_probes.py --runs-json PATH.json --output NEW_PROBE_DIRECTORY
```

Neither script modifies an input or overwrites an output directory. F is the common unmodified H0/D0 start, independent of minibatch seed, so it is measured once and explicitly aliased to F42/F43/F44. D checkpoints are loaded and their mean codes checked bitwise against F on all512/64/96 rows before their independent effect-probe results are aliased to F. D's *decoder* swap sensitivity is evaluated separately because its decoder changed.

The probe uses the existing centered/normalized current + linear-code + Schur-product kernel, the exact512 train folds, four current kernels, alpha grid, target normalization/floors, and old128 gripper bins. All selections are saved before observed64/96 predictions. Every head is reported; the evaluation cannot choose a repair seed/checkpoint based on observed effect labels. The zero/current-only CV and final results must reproduce the previous512 zero control. F uses highest/B8 mean-only code and is recomputed, not assumed equal to the historical medium-precision cached-code probe. Code caches, source hashes, all candidate scores, selected predictions, and fitted kernel artifacts are saved.

The swap script uses existing2900 query differences at rows `[0,9,18,27,36,45,54,63]`. The cached extractor swapped futures cyclically over all64 rows, so their source future cache rows are `[1,10,19,28,37,46,55,0]`; this is not a cyclic swap restricted to the eight rows. Current reference subtraction stays fixed. Posterior variance on each true/swapped query is produced by the original full64 head, clamped[-10,10], and never by an updated head. Report symmetric Gaussian KL, μ squared/Mahalanobis differences, logvariance differences, actual decoder output change, and factual-target MSE under true/swapped codes separately. Different fixed variances across true/swapped queries are expected; unchanged variance *function* does not mean equal variances for different inputs.

These metrics are finite-readout physical-effect utility and same-current future sensitivity. They are not conditional-MI estimates, proofs of action identity, camera invariance, or realizable action counterfactuals. The mean-code probe is distinct from single-sample Gaussian information. Both evaluation sets are already research-observed. Command-conditioned forecasting remains untested.

Implementation: [common loader](local_repair_evaluation_common.py), [effect probes](evaluate_local_repair_probes.py), [swap diagnostics](evaluate_local_repair_swaps.py), [synthetic tests](test_local_repair_evaluation.py). Six synthetic tests pass: completed mean-only checkpoint roundtrip, complete-run-set enforcement, incomplete/wrong endpoint rejection, analytic Gaussian distances against PyTorch distributions, train-only selection over the full fixed grid, and identical-code kernel equivalence. [Schema preflight](local-repair-evaluation-schema-preflight.json) records actual512/64/96 shapes/row verification, physical-label hashes, source hashes, and swap indices without probe fitting. [Completed schema check](local-repair-completed-schema-check.json) additionally verifies all D42 mean codes equal F exactly; HD42 mean codes differ and its drift-scope-failure flag is preserved, not filtered out.
