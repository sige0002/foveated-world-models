## 1. Verified range incompatibility in the physical auxiliary path

The corrected loader maps each endpoint state to approximately[-1,1] on the training range (`lerobot_robomind.py:26–30,175`). Official collate takes **end minus start**, without a factor of one-half (`collate.py:46–53`). The resulting delta can be in[-2,2]. Yet `StatePredictor.forward` ends with `torch.tanh` (`lam_decoder.py:216`), restricting each predicted delta to[-1,1]. A full gripper transition across the training min/max would demand ±2 and is impossible to reconstruct exactly.

For a target coordinate d, the squared-error infimum under this output restriction is `max(|d|-1,0)^2`. The batch's auxiliary floor is its masked sum divided by the number of valid coordinates, matching `eef_reconstruction_loss` (`utils.py:102–114`). If targets outside[-1,1] occur, the constraint is genuinely active. The logit gradient is `2*(tanh(a)-d)*(1-tanh(a)^2)/Nvalid`; it can vanish near saturation even while an irreducible physical error remains. This is a **shared official-code mechanism**, not a local transplantation discrepancy.

**Discriminating measurement, no fit needed:** count |d|>1 per coordinate and episode in the actual corrected pairs; compute the above floor; measure pre-tanh logits, `1-tanh(a)^2`, and auxiliary gradients to sampled z on those same examples versus in-range examples. If no out-of-range targets occur, or no saturation appears, this cannot explain weak gradients in this run. If active, it establishes an auxiliary limitation, not the cause of visual z collapse. A later isolated matched-state-head comparison could use2*tanh or an unbounded linear output, with scale/loss controls; it must not alter the live training or be claimed solved without a comparison.

## 2. Task gradients can lose to KL because both predictors have current-information bypasses

The visual decoder receives current patches and z; the physical predictor concatenates z embedding with **current state embedding** (`lam_decoder.py:207–216`). Therefore low task loss does not require z if current information predicts typical outcomes. The physical loss is added, not detached: `total_loss = visual + beta*KL + lambda_aux*state_loss` (`lam_lightinng.py:677,711–719`), current beta5e-5 and lambda_aux1. The visual objective averages SmoothL1(beta.1) over all feature coordinates (`lam_lightinng.py:655–657`); it does not emphasize rare moving regions. This can favor common current/background predictions, but actual prevalence is a measured data property.

The VAE draws a fresh sample during training (`vq.py:68–71`), whereas inference uses mu (`vq.py:98–103`). A nearly input-independent posterior can let the decoder learn to suppress random z. With fixed diagonal Gaussian notation, the analytic KL derivatives are `beta*mu` and `0.5*beta*(exp(logvar)-1)`; actual reconstruction/auxiliary gradients depend on decoder Jacobians. A small numeric beta alone cannot establish that KL is negligible, and a large total-gradient norm does not establish useful future-dependent gradients.

**Discriminating measurement:** on the same real training batch, augmentation and epsilon, separately backpropagate visual, auxiliary and KL terms to (a) mu/logvar, (b) encoder out_proj, (c) decoder action_in_proj. Record component norms **and pairwise cosines**, then actual optimizer updates/parameter-relative update norms. Also record state-predictor output changes under fixed-current common-epsilon posterior swaps, and compare actual state loss with zero-delta/current-only predictions. If visual+auxiliary gradients materially dominate KL and updates reach the encoder while future sensitivity still contracts, “KL overwhelms learning” is not supported. If aux error is low but z-Jacobian/aux gradients vanish and current-only predictions match, the auxiliary is not providing a useful z signal on those examples. A future-trained stronger current-only state model would require a separate protocol; swapping alone is exploratory and potentially OOD.

## 3. Locate response loss before attributing it to the encoder

There is an explicit bottleneck chain:1024D query →32D linear projection (`lam_encoder.py:29–34,121–123`) →learned LayerNorm →mu/logvar maps and clamp (`vq.py:38–58`). LayerNorm removes a scalar mean direction and attenuates scale changes; it does not delete arbitrary directional information. Current logvar clamp[-10,10] also produces zero derivative outside the unclamped range. These are official mechanisms, not newly discovered local bugs, and earlier legacy measurements cannot substitute for the current checkpoint.

**Discriminating measurement:** fixed current, true versus fixed alternate future, highest precision, compare differences at query, projected p, normalized p, mu/logvar and decoded output, with same-magnitude isotropic-direction controls. Separately report unclamped logvar saturation. If query response is already absent, changing decoder utilization cannot repair that upstream response. If query/p responds but normalized/mean representation does not, the bottleneck geometry is implicated. If mu/logvar responds but decoder output does not, the immediate limitation is utilization rather than no encoded future difference. Finite response measurements still do not identify action versus camera information or prove a mutual-information bound.

## Runtime audit priorities and stopping rule

First perform the target-range count/floor and the component-gradient/update audit; these provide stronger evidence than another global swap score. Use checkpoint optimizer state to verify encoder/VAE parameter membership and step counts, correct resumed LR, finite moments and actual nonzero updates. Current warmup5000 is LR scheduling only: it does not disable VAE or auxiliary loss. The run uses batch2 and10000 total updates; this is a limited local training regime, not official mixed-data exposure. Neither “too few steps” nor “batch too small” is a demonstrated cause without a matched intervention.

A causal conclusion requires both the corresponding runtime signature and a later isolated corrective intervention that restores z usefulness under the same data and budget. Until then distinguish: (i) verified range restriction, (ii) measured dominant gradient/update mechanism, (iii) proposed explanation. Do not pause or change the ongoing training to test these hypotheses without an explicit new experimental action.
