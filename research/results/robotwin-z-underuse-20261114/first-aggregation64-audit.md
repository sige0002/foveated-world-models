# 最初の集約ブロックで生じる方向集中

同じ FP32 検証64組で、候補3000更新と公式公開重みを比較した。候補では16個の attention head のうち **head 9（0始まり）が集約後 value の分散の80.985%を占め、その head 内の PC1 割合は99.429%** だった。続く attention 出力投影がこの主要方向をさらに増幅する。これは現在の forward で偏りを作る機構の測定であり、その重みを生んだ学習履歴・損失の原因までは確定していない。

## どこで偏るか

PC1 はサンプル間の中心化共分散の最大固有値割合。PR は固有値の participation ratio。トークンを持つ段では、各サンプルの全トークンを連結したベクトルで計算し、トークンを独立サンプル扱いしていない。

| 段階 | 公式 PC1 | 候補 PC1 | 公式 PR | 候補 PR |
| --- | ---: | ---: | ---: | ---: |
| 共通 DINO 特徴入力 | 4.358% | 4.358% | 53.44 | 53.44 |
| 入力投影 | 4.696% | 5.674% | 52.65 | 47.21 |
| context LayerNorm | 4.617% | 5.637% | 53.26 | 47.69 |
| V 投影・全トークン | 5.117% | 12.412% | 50.10 | 24.02 |
| attention による value 集約・head 連結 | 6.895% | 86.214% | 37.08 | 1.34 |
| attention 出力投影 | 27.009% | 99.097% | 9.55 | 1.02 |
| 学習可能 query の加算 | 27.009% | 99.097% | 9.55 | 1.02 |
| query LayerNorm | 19.109% | 90.875% | 13.24 | 1.20 |
| FFN linear 1 | 25.653% | 97.690% | 7.56 | 1.05 |
| GELU | 25.615% | 86.049% | 7.52 | 1.32 |
| FFN linear 2 | 54.895% | 93.899% | 2.81 | 1.13 |
| FFN 残差加算・ブロック出力 | 36.944% | 93.865% | 5.32 | 1.13 |

学習可能 query は全サンプル共通なので、その加算は中心化共分散を変えない。ここの query LayerNorm は候補の集中を99.097%から90.875%へ軽減している。後段の32次元 LayerNorm が集中を強めた既存の測定とは別の層である。FFN 加算後の分散は、候補では FFN 自身95.790%、query 自身0.119%、交差項4.091%で構成される。

## head 9 と入力・重み・選択の組合せ

- 公式では最大 head の分散寄与も8.848%で、各 head に分散が分布する。候補 head 9 では80.985%。この測定は head を平均せず、実装通り連結した value を使う。MHA が返す表示用 attention map の head 平均による現象ではない。
- 候補 head 9 が最大確率で選択した位置は、64組中62個の異なる frame/spatial token 位置だった。特定位置へ固定されているわけではない。分散寄与の大きい4組を除いても、この head の PC1 は99.349%だった。
- head 9 が選んだ位置の特徴を段階ごとに見ると、DINO 入力 PC1 **9.060% → 入力投影51.445% → context LayerNorm41.785% → head 9 の V 投影99.430%**。実際の attention 加重和でも99.429%。全位置の特徴が最初から一次元という結果ではなく、選択された入力と学習済み投影の組合せでほぼ一方向になる。
- この head の V 重み64×1024の最大特異方向エネルギーは47.669%、PR4.311。公式の各 head は最大方向10.165〜13.644%、PR15.915〜22.123。候補の重みも数学的な rank 1 ではない。
- 候補の全 head 集約 value の第一主成分は、出力投影後の分散の98.603%を説明する。その方向の二乗 gain は、残り方向の入力分散加重平均に対し11.290倍。公式では対応する割合15.441%、gain 比2.466倍だった。
- 同じ64組の **head 9 の PC1 score と最終 μ の PC1 score は絶対相関0.940736、R²0.884984**。符号は主成分の任意性に依存するため絶対値を使用した。この相関は物理状態を正しく表している証明ではない。

## attention の鋭さだけでは説明できない

各 head の最大 attention 確率の平均は公式0.98436、候補0.96655。両者とも鋭く、候補だけの softmax 飽和とは言えない。未来フレームへの平均質量は公式47.214%、候補50.578%、候補 head 9 は59.982%。これは未来入力を割り当て先に含むことを示すが、未来情報を適切に符号化した証明ではない。

候補 head 9 の選択位置の DINO 特徴ノルム順位は、各サンプル内で平均50.6 percentile。最大ノルムの位置を単に選び続けているという説明も、この測定では支持されない。

保存した attention 確率を P、value を V とし、サンプル平均と差分で `center(PV) = P̄ ΔV + ΔP V̄ + center(ΔP ΔV)` に分解した。候補の集約後分散に対する各項自身の分散は、平均 attention を固定した value 変動5.668%、平均 value を固定した attention 変動3.311%、両者の相互作用79.652%。交差項を含めると100%になる。公式の対応値は15.798%、22.492%、66.147%。固定化は保存値上の代数分解であり、モデルを変更して再学習した結果ではない。

## 再現性と範囲

新規 [測定スクリプト](../../trace_robotwin_first_aggregation.py) は公式ソースの入力投影・位置埋込・CrossAttentionBlock をそのまま実行する。後段24層を構築せず前段17 tensor を厳密ロードし、forward の一時 wrapper で観測した。通常の forward hook は使っていない。64組全てで、無観測実行、前回の全 encoder 実行で保存したブロック出力、PyTorch と同じ QKV/attention 再計算の差が **全て0**。観測前後の重みハッシュも一致する。

GPU 実 peak は168,350,208 bytes（160.55 MiB）、reserved196 MiB。16組 preflight 後に64組を実施し、後者の測定・統計・保存は36.7秒。GPU評価は終了済み。新規学習・checkpoint 更新・既存実行ファイルの変更は行っていない。

一次測定の全 trace/PR/共分散・重みスペクトル・parity は、このホストの SSD1 にある [測定原本](/media/sadasue/SSD1/foveated-world-models/runs/robotwin-loss-ablation-b4-20261114/evaluations/first-aggregation64-fp32-20261114/results.json)。head別・選択位置・LayerNorm 分解・PC相関は [CPU分解 JSON](first-aggregation64-decomposition.json)、再現コードは [analyze_robotwin_first_aggregation.py](../../analyze_robotwin_first_aggregation.py)。ソース・checkpoint・入力・保存 tensor の SHA256 をそれぞれ記録している。

この64組の結果を512組の数値と混同しない。head番号は同じモデル内部の識別子であり、公式と候補の同じ番号が同じ意味を担う保証もない。現時点で確認できたのは、候補における特定 head の value 変動集中と投影による増幅、および最終 μ への強い対応である。
