# 共通FP32評価の事後分布・方向別信号監査

対象は最終FP32 v2評価の同じ512ペア。公式リリース、`kl_mse`（MSE＋β=1e-5、3000更新）、他3条件を比較した。[再現スクリプト](../analyze_robotwin_posterior_geometry.py)と[数値・入力SHA・定義](robotwin-posterior-direction-audit-20261114.json)を保存した。CPUのみ、学習・モデル変更なし。旧10000更新モデルの潜在表現は混在させていない。

## 平均ノイズ比が一致しても、方向別の構造は一致しない

|指標|公式|kl_mse 3000|
|---|---:|---:|
|μの分散の総和|6.962632|0.200811|
|期待ノイズ分散の総和|18.836487|0.541603|
|全体のノイズ比|0.730121|0.729516|
|各ペアのノイズ分散総和の中央値|18.824228|0.528178|
|同、最小–最大|15.388524–22.598114|0.526128–0.579372|
|ノイズの大きい上位6ペアの総ノイズ占有率|1.3817%|1.2525%|
|μ共分散の最大固有値の分散占有率|22.2283%|99.9044%|
|μ共分散のエントロピー有効ランク|8.9634|1.0082|
|方向別の信号／ノイズ比が1を上回る方向数|11|1|

平均値の一致は少数の異常なノイズ値で生じていない。ただし分散の総和は方向を区別しない。

`C = Cov(μ)`、`N = diag(mean(exp(logvar)))` と定義し、`N^(-1/2) C N^(-1/2)` の固有値を調べた。これは `(C,N)` の一般化固有値であり、両共分散に同じ可逆な線形座標変換を適用しても変わらない。公式は11方向が13.63〜1157.41、12番目は0.00577。候補は1方向が14.8958、2番目は0.01040だった。

μの99%の分散を含む主成分部分空間は、公式で11次元、候補で1次元。その空間に入るノイズは、全ノイズの公式0.754%、候補2.696%だった。公式の大きな総ノイズの多くは、μの信号が小さい方向にある。この配置は単一のノイズ比では表現できない。

これらは標本の二次モーメントである。「情報が1ビット」「数学的にランク1」「意味のある動作が1種類」という結論ではない。事後ノイズは入力依存で、ここで使う `N` はその平均である。

## 未来入力への依存は、候補自身の尺度では消えていない

`δ = μ(現在,未来) − μ(現在,現在)` とした。`sqrt(E||δ||²) / sqrt(tr(C))` は公式1.4815、候補1.0194。μ共分散で白色化し、最大固有値の1%より大きい方向だけで測ると、各方向当たりの変位RMSは公式1.5068（11方向）、候補1.0194（1方向）。候補の変位エネルギーの99.8994%がこの1方向に入る。小さな固有値を逆数にすると数値誤差や微小方向を拡大するため、JSONには切り捨て閾値を変えた結果も記録した。

同じ評価で平均μへの置換による未来特徴MSE増分は公式0.095474、候補0.004393、未来入力を現在入力に置換した増分は公式0.193003、候補0.007892だった。これらは**決定論的μ**をdecoderへ渡す評価で、ノイズは注入していない。ノイズの配置は学習済み事後分布の性質であり、この評価の誤差差を直接生むノイズ計算ではない。現時点で確定したのは、候補の入力依存がほぼ一方向に集中し、公式とのdecoder出力への影響差も残っていること。学習履歴上の原因はこの監査だけでは確定しない。

## 状態ラベルとの関係：gripper一本という仮説は未確認

共通FP32検証cacheの状態・差分が、旧probeのラベルと512件すべて完全一致することを確認した。旧probeから利用したのは行IDと状態ラベルだけで、異なる精度の潜在コードは使っていない。訓練ラベル2048件の差分分散のうち、gripper2成分が83.70%（左43.02%、右40.68%）、XYZ6成分が7.85%、quaternion8成分が8.45%。検証512件ではgripperが85.23%だった。これは正規化後ラベルの分散・定数予測時のMSE配分であり、実際のg残差やencoder勾配の配分ではない。

候補の第1主成分の単変量相関は、右gripper差分で `r=-0.293`（R²=0.086）、左gripper差分でR²=0.0156。現在の左X座標との相関は `r=0.411`（R²=0.169）で、単純なgripper軸とは判定できない。

さらに第1主成分方向への `δ` の射影では、左X差分との相関が `r=0.503`（R²=0.253）、右X差分でR²=0.0758。一方、gripper2成分をまとめた分散加重R²は0.00717、XYZ6成分では0.07087だった。現状の一方向は文脈と動作の両方に関係し、gripperだけへの集中と断定する根拠はない。公式も含めた第1〜4主成分の全成分相関をJSONに保存した。これは同じ512件内の記述統計であり、別データで測ったprobe精度ではない。


別の同形式の事後コードは `--source DIR --models ARM... --output FILE --skip-label-analysis` で解析できる。各 `DIR/ARM/posterior-codes.pt` に `mu`、`logvar`、`current_only_mu`、行IDのSHAが必要。既存の `results.json` があればdecoder介入差も集計する。入力精度・対応行の同一性は、別実験について別途確認する必要がある。

## 追検証：未来特徴出力全体の完全定数化は除外できる

512件の正解未来特徴 `y_i` から最適な共通定数 `c=mean_i(y_i)` を作り、`mean_i mean_coordinates((y_i-c)^2)` をCPUで計算した。空間・チャンネルの形状 `[1,256,768]` は保持している。

|予測|同じ512件の未来特徴MSE|
|---|---:|
|全正解を見て最適化した共通定数|0.57956953|
|候補の実際の予測|0.35814698|
|公式の実際の予測|0.31342677|

候補は最良の共通定数より38.20%小さい誤差だった。この定数は評価対象の正解をすべて見て最適化しているため、この512件に同じテンソルを出すあらゆる定数予測の下限である。したがって、候補のdecoderが全件に完全に同じ未来特徴を出している状態は除外できる。一方、decoderは現在画像を別経路から受け取るため、これはzの表現縮退を否定せず、動作を十分正確に予測できる証拠にもならない。

測定上区別できたのは「μのサンプル間変動のほぼ一方向への縮退」と「decoder出力全体の完全定数化」であり、前者は確認、後者は除外された。[定数予測の数値と根拠](robotwin-constant-feature-baseline-20261114.json)、[再現スクリプト](../analyze_robotwin_constant_feature_baseline.py)を保存した。
